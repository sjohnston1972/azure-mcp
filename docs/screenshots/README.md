# Screenshots

Drop the following PNG files here and the project README will pick them up automatically.

| Filename | What it should show |
|---|---|
| `workspace.png` | Two-pane layout: topology canvas on the left, chat panel on the right, left rail with Topologies tab visible. |
| `build.png` | A Claude-built topology rendered on the canvas (e.g. a small App Service + SQL design), with the Bicep drawer open. |
| `push.png` | The stage bar with focus on Push, the styled confirm dialog, or the chat panel mid-push showing `Calling deploy_bicep` in the activity row. |
| `activity.png` | Close-up of the activity row above the composer — verb (Thinking / Drafting / Calling deploy_bicep) plus elapsed time. |
| `scheduler.png` | The Scheduler modal with a couple of saved templates, preset cron chips, and an active schedule listed. |

Recommended size: 1600×1000 or similar. JPG also fine if you prefer (update README image paths accordingly).

The screenshots aren't checked in by the project author because the local environment can't capture browser output — they need to be added by hand from a real session.
